1. Project Overview

This project analyzes the Brazilian Olist E-commerce dataset using Microsoft Power BI. It focuses on overall e-commerce performance, delivery efficiency, seller performance, freight costs, product sales and customer reviews.

The objective is to transform raw e-commerce data into meaningful business insights through interactive dashboards.

2. Business Objectives

- Analyze total order volume and order status distribution.
- Evaluate on-time delivery performance.
- Identify states with higher delivery delays.
- Analyze seller performance based on order volume.
- Examine freight costs across seller states and product categories.
- Understand customer review score distribution.
- Evaluate the relationship between delivery delays and customer satisfaction.
- Identify top-performing products by order volume.

3. Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
